### About Me  

Hello, I am a student from Indonesia who focuses on indie game development and open-source software. I build digital tools and interactive programs to solve real-world problems.

1. **Estuary Interactive:** My commercial indie game development studio.
  * Echoes of Ashes
2. **Ciptacode Projects:** My personal initiative dedicated to creating free, open-source, and ad-free software for the community.
  * Ciptacode Chess Tournament Manager
  * Ciptacode QR Code Generator
  * Ciptacode Video Downloader
3. **Achievements:**
  * Winner of 1st Place at the National FIKSI Competition for the *Palmurix* health project
  * 1st Place for Duta Pelajar Sadar Hukum Kutai Timur with the *SADAR* simulation game.
  * 2nd Place for PERCASI CUP Kutai Timur
4. **Current Focus:**
  * Learning Godot Engine architecture
  * Database management
  * Game logic systems
  * Low-level computing mechanics.
5. **Interests:**
  * Chess
  * Writing
  * Coding
  * Boxing.
